Export

GEDCOM 5.5.1 is the interchange format every major genealogy program reads — use it to move this tree into Ancestry, FamilySearch, Gramps, Legacy or RootsMagic. Anyone flagged living is exported by name and relationship only, with dates and places withheld — the JSON backup is the lossless copy.

The shareable branch is a single self-contained page — four generations back and three forward from whoever is selected, sources included — for emailing a relative who will not open a GEDCOM.
